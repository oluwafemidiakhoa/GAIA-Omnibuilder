# GAIA Universal Skills Bridge — v0.7 local MVP

Run `python -m unittest discover -s tests -v` and `python bridge.py --out portable-exports` from the project root. Choose a fresh output directory. No network or credentials required.

Each skill gets a portable `skill.zip`, `context.md` and unsigned `passport.json`. The catalog indexes package identity and static review findings. Codex and Claude Code directory layouts are generated separately. ChatGPT and Claude web uploads require manual installation and have not been verified; Gemini web and other models can use the context file manually, not as a native installed skill. Include supporting references when applicable.

The source was recovered from the v0.6 release archive, not a fresh GitHub checkout. The original 22 SKILL.md snapshots match the original skills archive byte for byte; 45 supporting files were restored. All 84 legacy tests and 14 bridge tests passed on Linux. Windows v0.7 and live platform compatibility remain untested. The scanner accepts only bounded UTF-8 text resources, rejects executable extensions and common secret patterns, and flags selected suspicious instructions. It is heuristic, not a malware detector or authorization mechanism. No untrusted content is executed. Use a stable local source directory under operator control; concurrent filesystem mutation, hostile filesystem users and all Windows reparse point variants are outside the tested threat model. Output can be partial if a disk error occurs; discard incomplete exports. The generic context file includes only the entrypoint. Passports are unsigned, with no authenticated publisher or behavioral proof. No hosted registry, web dashboard, tenant isolation, billing, or API integrations are delivered.

To integrate with GitHub, review the new bridge.py, tests/test_bridge.py, BRIDGE.md and restored supporting skill files on a feature branch. Do not overwrite existing repository changes or merge automatically. Prior release manifests remain historical and do not cover this release.
