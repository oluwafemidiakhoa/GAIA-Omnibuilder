# Candidate specialists

Use only if actually available. Existing skills remain unchanged: Scientific Research Agent, frontend design, Production Hardening Engineer, Agent Observability Engineer, Autonomous Development Orchestrator, Business Development Agent. Prefer these for their existing specialties.

- `software-architecture-specifier`: Design software architecture, APIs, schemas, ADRs and migration plans before implementation.
- `data-analysis-pipeline`: Build reproducible statistical, data engineering and machine learning analyses from supplied or authorized data.
- `scientific-experiment-designer`: Translate scientific evidence into falsifiable experiments and preregistered analysis plans.
- `business-operations-planner`: Design operating models, process improvements, KPI systems and business economics.
- `product-design-system-planner`: Design product journeys, accessible UX, information architecture and reusable design systems.
- `artifact-production-studio`: Produce polished documents, presentations, spreadsheets, diagrams and other supported artifacts.
- `security-threat-modeler`: Model trust boundaries, authorization failures, abuse cases and security requirements before implementation.
- `deployment-release-manager`: Plan and verify staged deployment, CI/CD, database migration, canaries and rollback.
- `evaluation-verification-lab`: Design and execute independent acceptance tests, regression suites and adversarial evaluations.
- `connector-integration-planner`: Design MCP, API and application integration contracts with narrowly scoped authorization.
- `skill-factory`: Create candidate specialist skills to close demonstrated capability gaps using the supported skill creation workflow.
- `evidence-ledger`: Maintain append-only evidence records for builds, research and decisions with explicit provenance.
- `failure-recovery-engineer`: Diagnose failed builds and perform bounded reversible corrections with regression checks.
- `benchmark-laboratory`: Compare skill, agent and model workflow versions using frozen representative benchmark suites.
- `ml-model-engineer`: Build and validate machine learning training and inference pipelines, including model selection and deployment readiness.
- `enterprise-database-engineer`: Design and troubleshoot SQL databases, data warehouses, indexes, migrations and operational diagnostics.
- `knowledge-system-architect`: Design RAG, knowledge graphs, search and provenance-aware retrieval systems.
- `innovation-validation-lab`: Convert novel product or scientific ideas into testable novelty and feasibility claims rather than declaring breakthroughs.
- `cost-performance-engineer`: Optimize computational and AI workloads for measurable cost, latency and quality tradeoffs.
- `workflow-automation-architect`: Build repeatable business or engineering automations with explicit triggers, state and recovery.
- `technical-communication-studio`: Create rigorous technical documentation, manuscripts, runbooks and developer guides from verified sources.
